About Bubble Shooter

Bubble Shooter is a free bubble-popping puzzle game. Aim, shoot and match three or more bubbles of the same colour to clear the board. It is built by CodeCrafix, an independent studio that also builds custom mobile games for clients.

Game features

  • Match and pop 3 or more bubbles
  • Simple one-touch controls
  • Fun animation and colourful visuals
  • Classic arcade action, free to download

How to get Bubble Shooter

  1. Tap Download Now to open the game on the Amazon Appstore.
  2. Install it for free on a supported device. Amazon ended the Appstore on regular Android phones in August 2025, so it is available on Fire tablets and Fire TV.
  3. Open the game and start popping.
